## W5 / W6 修的到底是哪半格

舊寫法把「換」與「記」綁在一個語句上:

```python
previous[sig] = signal.signal(sig, ignore)
```

`signal.signal()` 回來的那一刻處置**已經換掉了**,而 `previous[sig]` 的指派還沒
發生。信號落在那一刻(或任何事在那裡拋),`finally` 的還原迴圈看不到這個 `sig`:

- `_signals_deferred` 漏下的是 `ignore` → 之後**誰按 Ctrl-C 都沒反應**,而且看不出
  是誰改的(`cli.main` 是函式庫呼叫端也會用的進入點);
- `_signals_as_exit` 漏下的是 `_stop_on_signal` → 之後行程收到 `SIGTERM` / `SIGHUP`
  都會從一個早就結束的 `ui` 裡丟出 `_Stopped`,比沒裝更糟。

#42 L-5 修的是「整個迴圈漏在 `try` 外」(`finally` 根本不在路徑上),這一條修的是
迴圈**裡面**剩下的那半格。先記再換之後窗口的兩側反過來:記了但還沒換的話,
`finally` 把一個「本來就是它」的處置再裝一次,無害。

### 邊角:`except ValueError` 為什麼還要覆寫 `previous[sig]`

先記再換之後,`getsignal()` 已經把值寫進 `previous[sig]` 了,而接著的
`signal.signal()` 可能丟 `ValueError`(不是主執行緒)。那一格的意思是「**根本沒裝
上**」,所以 `previous[sig]` 必須被覆寫成 `_NOT_INSTALLED`——否則 `finally` 會在
非主執行緒上呼叫 `signal.signal()` 去「還原」一個我們從未裝上的處置,而那又是一個
`ValueError`,從 context manager 的 `finally` 裡冒出去。這是改順序時唯一新長出來的
邊角,兩個函式都寫了註解。

### F-3 [不擋] ⚠️ **不改**,理由如下(兩個候選修法都實跑過)

F-3 描述的窗口確實存在,而且複審自己標了「今天碰不到」:舊處置由 C 層裝
(`getsignal` 回 `None`)**且**例外剛好落在 `getsignal` 之後、`signal.signal` 之前
時,`finally` 會把一個我們**沒碰過**的 C handler 改成 `SIG_DFL`。

問題是「還原迴圈可加『仍是 `None` 的不動』」這個修法會把 **F-1 剛要求釘住的那道
防護拆掉**:`None` 的正常來路是「我們**真的**換上去了,只是拿不回舊的那個」,那一格
非退 `SIG_DFL` 不可——把 `_stop_on_signal` / `ignore` 留在行程上更糟(Ctrl-C 沒反應、
或從一個早就結束的 `ui` 裡丟出 `_Stopped`),而這正是 `_signals_as_exit` docstring
寫明的選擇。實跑:

| 候選修法 | `test_cli_signals_restore.py` + `test_cli_ui.py` |
|---|---|
| A:`if handler is _NOT_INSTALLED or handler is None: continue` | **2 failed**, 143 passed(紅的是 F-1 要求的那條與它的 `_signals_deferred` 版) |
| B:還原時以身分比對判斷「我們真的換上去了嗎」(`signal.getsignal(sig) is not ignore → continue`) | **2 failed**, 143 passed(同兩條:F-1 的量法把 `getsignal` 攔成 `None`,我們認不出自己裝的 handler) |
| 不改(現況) | **143 + 2 = 145 passed** |

B 看起來是「對的」修法,但它與 F-1 **指定的證人形狀**互斥:那條證人把 `getsignal`
全域攔成 `None`,於是還原時也認不出自己剛裝上去的 handler。要兩者並存,只能在
`signal.signal` **之後**再寫一次「已裝上」的記錄——而那恰恰是 W5 關掉的「已換、未
記」窗口的鏡像:記錄沒寫成,我們的 handler 就永久留著。

兩種壞法的方向也不對等:現況壞在「把一個沒碰過的 C handler 降成 `SIG_DFL`」(原處置
本來就拿不回來),候選壞在「把我們的 handler 永久留在行程上」(票文與 docstring 都
點名這是更糟的那一種)。所以本輪**不動還原迴圈**,把這段取捨寫在這裡;真要收掉這一
格,該是一張獨立的票(連 F-1 的證人形狀一起重新設計),不是順手改三行。
